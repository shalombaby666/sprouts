# Sprouts

[Открыть приложение](https://shalombaby666.github.io/sprouts/)

Карточки английских слов: обучение, повторение, выбор ответа, ввод перевода, просмотр и статистика. Две колоды, 76 слов. Прогресс начинается с нуля и хранится только в localStorage вашего браузера. Сервер, MySQL, аккаунт и Claude не нужны.

Откройте index.html или запустите `python -m http.server 8000`. Онлайн загружаются только шрифты Google; системный шрифт работает без них. Удаление данных сайта сбрасывает прогресс, синхронизации между устройствами нет.

## Перенос
Исходный HTML-артефакт адаптирован для автономной работы. В words.js — словарное содержимое; личная статистика автора не публикуется. Изменение колод вручную: words.js. Для сброса удалите ключ sprouts-progress-v1 в хранилище сайта.

## Резервная копия прогресса
Внизу страницы откройте Keep your progress safe. Download backup сохраняет JSON. На другом устройстве выберите файл и подтвердите Replace current progress. Это ручной перенос, не облачная синхронизация. Импорт проверяет версию, состав колоды, этапы и даты повторения, статистику. Словарный текст из файла не загружается. Ошибка или отмена сохраняет текущий прогресс.
